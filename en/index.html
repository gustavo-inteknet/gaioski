01 About

About

Monitoring gives you the warning. But a warning only becomes protection when someone decides to act.
from a real case, 2026

I started in 2015 as a support intern, fixing printers and creating Active Directory accounts. Eleven years later I'm still at the same company, IntekNet, now in the C-suite as CCO. Along the way I worked through servers, networks, firewalls and Microsoft 365, and more recently through leading the team that looks after all of it.

If that path taught me anything, it's that almost no IT problem is purely technical. The file that won't open from OneDrive is an information architecture problem. The backup that fails to restore is a missing second layer. The new hire who spends day one waiting for access is a process problem. I like finding the cause before swapping the part.

Today I lead new business, partnerships and company growth. In practice that means stepping in before the contract: assessing the environment, designing the solution architecture and making sure what we propose is what operations can actually deliver.

04 Field notes

Real stories, no client names.

Continuity01

The backup that failed when it mattered

Situation
Monitoring flagged a failing disk. The replacement got postponed, the disk died, and the backup, tested every month, failed to restore.
What we did
We restored from the second backup, made with a different tool and independent from the first.
Result
Server back online. After the incident, the client approved RAID 1 disks, a server replica and cloud backup.

One backup is a bet. Redundancy means layers that don't depend on each other.

Microsoft 36502

The 255-character limit

Situation
After a migration, files opened in the browser but not on the PC: the path exceeded the synced Windows limit.
What we did
Before moving anything, we redesigned the structure: shallow folders, short names, libraries and metadata.
Result
A migration without the sync errors nobody can explain later.

Silence isn't health

The company judged IT by the absence of complaints.
